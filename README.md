# 3Fase

Sito web del gruppo musicale **3Fase** — cantautori, produttori e dj.

🔗 **Sito ufficiale:** https://sites.google.com/view/trefase

## Struttura del repository

```
.
├── index.html          # Landing page animata (questa pagina, su GitHub Pages)
├── img/                 # Immagini del sito (banner, foto, loghi)
└── README.md
```

Questo repository ospita **solo la landing page** pubblicata tramite GitHub Pages: una schermata di benvenuto con banner animato che rimanda al sito ufficiale, ospitato su Google Sites, dove si trovano tutte le sezioni (Chi Siamo, Social, Repertorio, Componenti, Galleria, Contatti).

## Anteprima

La landing page mostra:
- Banner animato a piena larghezza con effetto Ken Burns
- Logo del gruppo in alto a sinistra
- Titolo e tagline in sovraimpressione
- Pulsante che rimanda al sito ufficiale
- Footer con nota privacy e contatto email

## Privacy

Questa pagina (`index.html`, ospitata su GitHub Pages) **non utilizza cookie né strumenti di tracciamento**.

Il sito ufficiale linkato (ospitato su Google Sites) utilizza invece i cookie propri di Google, incluse le finalità pubblicitarie/di misurazione (es. `NID`, `ENID`), di competenza di Google. L'informativa relativa è disponibile direttamente su quel sito, con link alle policy di Google.
